# 合同及情景曲线

日期ISO公历。利率为非负年率，本金按每个工具共同计息，不同放款批次仍留来源；同日顺序为上一段利息结算／按登记资本化、放款、还本，费用按本日另记。资本化日利息不支付而加本金，之后继续计息；最后支付日结清未付利息。all-outstanding只允许最后一次还本，含已资本化本金。

30E/360定义为360*(Y2-Y1)+30*(M2-M1)+min(D2,30)-min(D1,30)，不另作二月月末修正。Actual/365F即实际天数/365。未登记资本化的普通宽限期只推迟还本，利息仍按interest_payment_dates支付。赠款maturity为null且无任何偿还。

各情景同一工具日历，利率从最近且不晚于重置日的明确报价取值，不外推至报价范围外；曲线必须覆盖所有现金事件，discount及fx为正。折现到valuation_date，fx表示每原币单位可换报告币。场景分位采用最小累计权重达到q的左连续逆分布。channel_shares对工具和为1，只分配不复制工具。

读取器检查日期与身份基本形状，不排事件、不计息或生成估值。
