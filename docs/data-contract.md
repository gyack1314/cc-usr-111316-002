# 合同及情景曲线

日期ISO公历。利率为非负年率，本金按每个工具共同计息，不同放款批次仍留来源；同日顺序为上一段利息结算／按登记资本化、放款、费用（现付或资本化）、还本。资本化日利息不支付而加本金，之后继续计息；最后支付日结清未付利息。all-outstanding只允许最后一次还本，含已资本化本金与资本化费用。

30E/360定义为360*(Y2-Y1)+30*(M2-M1)+min(D2,30)-min(D1,30)，不另作二月月末修正（月末对月末可能得到28或32天，见month-end-30e资料）。Actual/365F即实际天数/365（闰年按366真实天数，分母仍为365）。未登记资本化的普通宽限期只推迟还本，利息仍按interest_payment_dates支付；capitalization_dates表达利息资本化宽限。两类日期不得同日重叠。赠款maturity为null且无任何偿还、费用。

费用在`fees`中按合同日单列：`treatment="pay"`为当日现金费用，`treatment="capitalize"`当日加入本金并自该日起计息；不能默认免息。区间中途出现放款、还本、付息、资本化、费用或重置事件都切段；利率取最近且不晚于切段日的重置日的已登记报价，区间内不插用未来报价，重置范围外的事件按缺报价处理。

各情景同一工具日历，曲线必须覆盖所有现金事件，discount及fx为正。折现到valuation_date，fx表示每原币单位可换报告币。节点取已登记的精确有理数；节点之间对discount与fx分别按log线性插值（按真实日数权重），插值结果转回有理数参与全程演算，禁止外推至报价范围外。现金流先在发生日乘fx换报告币，再乘discount折现。

赠款等值（GE）＝放款现值－（本金＋利息＋必要费用）偿还现值，百分比以放款现值为分母；赠款GE只含放款，负等值如实保留，GE不是现金余额也不是债务豁免。另报借款人每年本息与费用（报告币现金口径，年度债务负担=本金+利息+费用）。每个工具附三条可追溯恒等式（本金、利息、费用），任一差额都能回到具体现金事件。

channel_shares对每个工具之和为1，多对多渠道按冻结份额分配而不复制工具；组合另给渠道加回校验（渠道放款现值之和=组合放款现值，差额必须为0）。情景权重之和为1；先逐情景完成合同演算，再按权重汇总均值与离散分位，分位用最小累计权重达到q的左连续逆分布，不先平均利率。

发布拦截（定位到工具与日期，整组不发布）：曲线/报价缺失或越界外推、还本超过未偿本金、同id多份合同、日历不完整或事件越界、份额与权重之和不为1、到期仍有未偿本金或未结利息。报告绑定方法版本与清单sha256指纹（binding.fingerprint），改合同或曲线即改指纹，必须新建结果，可用`cli verify`复核。

读取器检查日期与身份基本形状，不排事件、不计息或生成估值；`analysis_data.cashflow`负责结构校验、逐段演算、估值与汇总。
